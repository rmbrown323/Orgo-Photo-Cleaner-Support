Orgo Support

For help, feedback, or feature requests, email rmbrown323@icloud.com.

Reporting an issue

Please include:

  • Your iPhone model and iOS version.
  • The Orgo version and build shown in Settings → About.
  • What you were doing when the problem happened.
  • A screenshot or recording if it contains no private information.

Photo access

Orgo needs Photo Library read and write access for review and cleanup. Change access in iOS Settings → Apps → Orgo → Photos.

Deleting photos

Marking a photo does not delete it. Photos are removed only after you select Cleanup and confirm Apple’s system deletion prompt.

iCloud Backup

Automatic Backup is optional and can be managed in Settings → iCloud Backup. Orgo backs up review choices and settings, never photos. If Orgo reports that both copies changed, choose Restore iCloud Backup to keep the cloud copy or Replace iCloud Backup to keep this device’s copy.

Resetting Orgo

Settings → Reset All App Data clears Orgo’s review progress, choices, preferences, and local caches. It does not delete photos or change Photo Library permission.
